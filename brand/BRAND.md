# Cosmic Scale — Brand System

Channel: **Cosmic Scale** (@CosmicScaleShorts)
Niche: astronomy, size comparisons across the universe (subatomic → supermassive black holes).

## Palette
| Token | Hex | Use |
|---|---|---|
| `--void` | `#05070D` | base background (deep black-navy) |
| `--void-2` | `#0A1020` | background gradient stop / panels |
| `--nebula` | `#141B3A` | faint nebula tint |
| `--cosmic` | `#2F7BFF` | primary cosmic blue (logo sphere, UI) |
| `--cosmic-deep` | `#0A3D91` | shadow side of blue elements |
| `--ice` | `#5CC8FF` | cyan highlight / glow |
| `--lumen` | `#F2F7FF` | luminous white (text, stars) |
| `--muted` | `#8CA0C8` | secondary text / HUD |
| `--solar` | `#FFB54A` | sun / warm stars accent |
| `--ember` | `#FF5A3C` | red giants / danger accent |

## Typography
- Headlines / captions: **Inter Display Black** (or Inter Black), uppercase, letter-spacing -0.02em.
- Body: Inter Medium.
- Data / HUD / numbers: **JetBrains Mono** (tabular figures).

## Visual rules
- Deep space, never pure #000. Subtle vignette, fine star dust, soft blue nebula.
- Glow: 2-layer (tight cyan core glow + wide blue halo).
- Motion: continuous slow drift; scale jumps hit with a sub-bass impact.
- Captions: 2–4 words per card, pop-in, highlighted keyword in `--ice`.

## YouTube asset specs
- Profile picture: 1024×1024 PNG, circular crop safe, readable at 48 px.
- Banner: 2560×1440 PNG, all key content inside the central **1546×423** safe area, ≤ 6 MB.
- Shorts: 1080×1920, H.264 high profile, 30 fps, AAC 48 kHz.
